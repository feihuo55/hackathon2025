1. 系统概览

📋 项目信息

  • 项目名称: Custody Bank AI Process Automation Platform
  • 开发周期: 48小时
  • 团队规模: 4人
  • LLM模型: Claude 3.5 Sonnet (AWS Bedrock)
  • 核心技术: Chainlit + CrewAI + LlamaIndex + Chroma

3. 数据流设计

3.1 Flow 1: 基金净值查询流程

👤 用户输入
"查询富国天惠基金今天的净值"
↓
🤖 Intent Agent
识别意图：查询类 / 基金净值 / 富国天惠
↓
📚 RAG Service
搜索匹配服务 → 找到 getFundNAV
↓
⚙️ Mock Service
调用 getFundNAV(fundCode: "161005")
↓
💾 Memory System
存储交互记录到Episodic Memory
↓
📊 结果展示
净值: 3.2156 | 涨跌: +2.35% | 累计净值: 5.8765

3.2 Flow 2: 基金分红处理流程

👤 用户输入
"处理本周所有基金的分红派息流程"
↓
🤖 Intent Agent
识别意图：自动化流程 / 基金分红 / 批量处理
↓
📚 RAG Service
搜索结果：未找到匹配服务
↓
💬 Group Chat
BA Bot + Tech Bot 多轮对话收集需求
↓
📋 SIPOC Generator
生成流程文档和可视化图表
↓
✅ Human Approval
人工确认流程正确性
↓
🛠 Service Builder
AI生成 fundDividendProcessing 服务
↓
⚡ Execute Service
调用新服务处理分红
↓
📊 结果展示
处理完成：5只基金 | 分红总额：¥2,500,000

3.3 数据交互序列

🔄 关键数据流转

  1. 用户输入 → Chainlit：自然语言文本
  2. Chainlit → Agent：结构化请求对象
  3. Agent → Bedrock：LLM推理请求
  4. Agent → RAG：服务检索查询
  5. RAG → Chroma：向量相似度搜索
  6. Service → Memory：执行结果存储
  7. Agent → Chainlit：格式化响应
  8. Chainlit → 用户：可视化展示
